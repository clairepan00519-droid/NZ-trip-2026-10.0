# NZ Trip Family Sync v19

本版更新：
- 修正 9/25、9/26 行程交換後的市場營業日、住宿晚數與結尾文案
- 加入「今日模式」，依 Pacific/Auckland 日期自動定位當天行程
- 加入住宿快速卡：入住狀態、退房提醒、住宿導航與訂房頁面
- 評論、照片、景點、路線圖、清單與憑證刪除後可在 7 秒內復原
- 家人同步改用 Supabase Auth Email／Password，資料表不再允許匿名讀寫
- 加強同步文字轉義，降低惡意同步內容造成網頁腳本注入的風險
- 加強離線圖片快取與本機替代圖，離線時仍可查看文字行程、清單、憑證快取與手繪環線圖

## v19 必做一次的 Supabase 設定

1. 在 Supabase SQL Editor 重新執行 `SUPABASE_SETUP.sql`，把舊的匿名政策換成 authenticated 政策。
2. 到 Authentication → Providers，確認 Email 登入已啟用；建議關閉「Allow new users to sign up」。
3. 到 Authentication → Users，為每位需要使用網站的家人建立帳號。
4. 使用家人的 Email 與密碼登入網站。所有已授權帳號仍共用同一份行程資料。

## 離線使用方式

- 第一次必須在有網路時完整開啟網站並成功登入一次，瀏覽器才會建立離線快取與可信裝置記錄。
- 之後沒有網路時重新開啟網站，可點「離線查看此裝置快取」。
- 登入同步後，網站會預先快取使用者上傳的憑證、路線圖、清單附圖與景點照片。
- 離線時可閱讀行程、住宿、清單、本機資料與已預存圖片；天氣、外部導航、尚未看過的外站裝飾圖片及雲端同步需等恢復網路。
- 恢復網路後會重新驗證登入狀態並繼續同步。
